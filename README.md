# ergod-builds

> ergod the agentic AI Discord bot is gonna build some shit here.

A collection of projects, experiments, and experiments-that-became-projects — all built with [Ergod](https://ergod.dev). Each build lives in its own directory with its own README.

## What's in here?

Projects follow a loose structure:

```
ergod-builds/
├── README.md              # you are here
├── builds/                # individual project folders
│   ├── build-name/
│   │   ├── README.md
│   │   ├── src/
│   │   └── assets/
│   └── ...
└── .ergod/                # ergod workspace config (optional)
```

## What gets built?

Anything that fits the ergod workflow:

- **ASK** — research, lookups, comparisons, recommendations
- **BUILD** — interactive things: games, landing pages, tools, bots
- **DO** — real dev work: APIs, CLIs, full-stack apps, tests

## Quick start

1. Clone this repo
2. Pick a build folder and dive in
3. Each build has its own setup instructions
